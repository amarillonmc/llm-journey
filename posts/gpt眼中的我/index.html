GPT眼中的我

概览

你长期维护和开发多个技术与创作项目，尤其专注于基于 PHP 的网页游戏、论坛系统和服务器运维，同时也持续进行世界观设定、角色设计以及 AI 音乐创作。你偏好保留已有系统能力，在兼容现有内容的前提下逐步重构和自动化，并且习惯结合 AI 工具完成程序开发、美术和音乐等不同类型的创作。

PHPDTS 网页游戏

你的长期项目是非商业网页游戏 ACFUN 大逃杀（PHPDTS），代码仓库位于 https://github.com/amarillonmc/phpdts 。你计划以旧的 nouveau 模板为基础重新设计整个界面，但要求完整覆盖旧模板全部功能，不修改已有游戏内容。你还在推进 OpenCode Agent 自动化流程，希望实现规则书与角色集自动导入、分章节生成以及草稿到定稿的工作流，并要求整个流程不能比手工上传更复杂。你曾上传并讨论过包括 clubskills_1.php、revcombat、XML 模块清单和 help.htm 等核心文件，并持续设计教头 NPC、新技能体系以及相关战斗机制。

论坛与社区项目

你正在维护和翻新多个论坛系统。其中 Discuz! 6.1.0F 翻新版代码仓库为 https://github.com/amarillonmc/Discuz-6.1F_NemoMOD 。你的计划是在保留 Discuz 原有积分体系的基础上，移植抢车位、QQ 农场、QQ 牧场、QQ 餐厅等经典社区玩法，让这些小游戏直接使用论坛原生扩展积分，而不是建立独立游戏货币体系。你也持续收集旧版 Discuz 插件、主题以及历史资料，为论坛复刻工作提供参考。

服务器与开发环境

你长期维护 Windows Server、Linux、IIS、MySQL、Redis、Nginx 和 PHP 环境，并经常排查复杂运维问题。你部署着多个 PHP 项目，习惯设计自动备份方案，包括定期打包网站文件和 MySQL 数据库并自动保留最近几份备份。近期你还处理过 RDP 剪贴板异常、PHP CGI 异常行为分析、MySQL 服务偶发停止、CloudCone 网络问题、cPanel 环境以及 Windows Server 图标缓存等问题，并关注将 ChatGPT 或相关开发工具部署到远程 Windows Server 的可行性。

创作与世界观

你持续构建原创近未来世界观，包括湾城、时空特使、红杀组织以及一系列原创角色，并为角色设计机制、剧情、美术和游戏实现同步推进。你也经常制作《动物朋友》风格角色设定图、游戏王 DIY 卡图、场景插画和其他视觉创作，希望保持统一画风，同时允许调整姿势、构图和主题表现。对于游戏机制设计，你倾向于大胆引入新玩法，而不是简单替换已有机制。

AI 音乐创作

你订阅了 Suno AI Pro，并使用 DistroKid 发布作品。你持续策划多个概念专辑，包括 Still Session、Signals Through Concrete、赤色地平线下的回声、Waiting at the Edge of the Sky、Waiting Beyond the Storm、Sunbeam Circuit，以及探索极限混合风格的“打破不可能”系列。你希望同时获得中英文命名、Suno 提示词、曲目排序、歌词、叙事和 1:1 专辑封面，并特别关注 SHIKI 风格 Trance、The Sims 1 Build/Buy 风格纯音乐以及其他具有鲜明主题的专辑创作。

工具与硬件

你关注本地 AI 模型和开发工具的实际部署能力。目前使用 GPD Win Max 2（6800U、32GB），同时关注搭载 Ryzen AI Max+ 395 与 128GB 内存的新设备能够运行哪些文本、图像、音乐和视频模型。你也探索 Google AI、OpenClaw、RAMSAY 卡库系统等工具，希望将 AI 能力整合进自己的开发流程和项目中。
